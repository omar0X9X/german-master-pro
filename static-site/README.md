# تعلّم الألمانية 🇩🇪

موقع عربي RTL ينظم تعلم الألمانية من **A1 إلى B2** كمسار واضح، وليس كقائمة روابط عشوائية.

## الحالة الحالية

- **47 فيديو YouTube مرتب** كمسار أساسي:
  - A1: 15 فيديو
  - A2: 12 فيديو
  - B1: 10 فيديوهات
  - B2: 10 فيديوهات
- **36 مورداً تطبيقياً** للقراءة والكتابة والاختبارات والتمارين.
- كل فيديو له رقم وترتيب ونوع: درس أساسي / نطق / استماع / اختبار / مراجعة.
- الفيديوهات الطويلة لا تُستخدم كبديل عن المنهج؛ توضع فقط كمراجعة أو استماع طويل.

## المصادر الأساسية

- **Deutsch mit Ahmad Yaghi**: قواعد، مفردات، محادثة، تحضير امتحانات.
- **Easy German**: نطق، قواعد تطبيقية، استماع طبيعي، B1/B2.
- **DW Deutsch lernen**: Nicos Weg للاستماع A1/A2/B1.
- **German.net / Lingua**: القراءة حسب CEFR.
- **VHS-Lernportal / LangCorrect / DeutschAkademie**: كتابة وتمارين.
- **Goethe-Institut**: تدريبات ونماذج الاختبارات.

## طريقة الموقع

داخل كل مستوى:

1. خارطة طريق قصيرة.
2. **مسار الفيديوهات بالترتيب 01 → N**.
3. علامة «مكتمل» لكل فيديو.
4. قسم منفصل للمواقع والتمارين.
5. حفظ التقدم محلياً في `localStorage`.
6. الوضع الليلي + تصميم Responsive.
