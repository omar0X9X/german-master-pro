# German Master Pro 🇩🇪

مشروع عربي RTL لتعلّم الألمانية من **A1 إلى B2** كمنصة دراسة يومية، وليس كقائمة روابط.

## الفكرة

دورة التعلم داخل المشروع:

**شاهد → اقرأ → اكتب → اختبر → حوّل الأخطاء إلى مراجعات → راجع → تابع اليوم التالي**

## الموجود حالياً

- 4 مستويات: A1 / A2 / B1 / B2.
- **120 يوم دراسة**: 30 يوماً لكل مستوى.
- كل يوم يحتوي على:
  - فيديو أو أكثر مناسب للمستوى.
  - نص ألماني مختلف ومتدرج.
  - 3 أسئلة فهم بعد القراءة.
  - مهمة كتابة يومية مع حد أدنى للكلمات.
  - خانة كتابة داخل الموقع مع حفظ تلقائي وعدّاد كلمات.
  - 5 بطاقات مفردات.
  - مراجعات مستحقة من Spaced Review.
- **77 فيديو** في مكتبة الفيديو الحالية.
- الفيديوهات الأساسية مرتبة داخل 19 وحدة تعلم.
- الأولوية لقنوات موثوقة ومحتوى مناسب لـCEFR مثل Easy German وDeutsch mit Ahmad Yaghi وDW.
- بعض الفيديوهات تعرض Snapshot للمشاهدات/الإعجابات عندما تكون الأرقام قد تم التحقق منها علناً.
- لا يدّعي المشروع أن تعليقات فيديو ما «إيجابية» إلا إذا كانت لدينا بيانات موثوقة كافية عن التعليقات.
- 36 مورداً إضافياً للقراءة والكتابة والاستماع والاختبارات.
- 19 اختبار وحدة بإجمالي 57 سؤالاً.
- 80 بطاقة مفردات في نظام المراجعة.
- Study Engine يبني خطة اليوم حسب الوقت والتقدم.
- Spaced Review للمفردات وأخطاء الاختبارات.
- Streak وإحصائيات وتقدم حسب المستوى والمهارة.
- Dark Mode + Responsive + Mobile navigation.
- PWA / offline shell.
- البيانات والتقدم محفوظان محلياً في localStorage.

## برنامج 30 يوم

كل مستوى له 30 يوماً مستقلاً:

- **A1:** نصوص قصيرة جداً ثم أطول تدريجياً، وكتابة تقريباً من 20 إلى 70 كلمة.
- **A2:** من 70 إلى 120 كلمة تقريباً.
- **B1:** من 110 إلى 160 كلمة تقريباً مع رأي وسرد وحجج.
- **B2:** من 160 إلى 220 كلمة تقريباً مع مواضيع أكثر تجريداً وتحليلاً.

الهدف من هذا التدرج هو رفع الحمل اللغوي تدريجياً، وليس افتراض أن إنهاء 30 يوماً وحده يضمن شهادة CEFR.

## سياسة اختيار الفيديو

نفضّل:

1. أن يكون الفيديو مناسباً فعلاً لمستوى وموضوع اليوم.
2. قناة تعليم ألمانية موثوقة.
3. فيديو منفصل بموضوع واضح بدل فيديو «مستوى كامل» عندما يكون ذلك أفضل للتعلم.
4. تفاعل عام قوي عندما تتوفر أرقام عامة موثوقة: مشاهدات وإعجابات.
5. لا نعرض أرقاماً غير موثقة ولا نخترع تقييمات للتعليقات.

أرقام المشاهدات والإعجابات Snapshot وقد تتغير بعد تاريخ التحقق الموجود في `data/videos.json`.

## التشغيل محلياً

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

> لا تفتح `index.html` عبر `file://` لأن بيانات JSON تُحمّل بـfetch.
