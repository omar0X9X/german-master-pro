# Deutsch Road — تعلّم الألمانية

إعادة بناء كاملة من الصفر لمستودع `german-master-pro`.

## الهدف
موقع Static عربي RTL يساعد المتعلم من A1 إلى B2 بدل أن يكون مجرد قائمة روابط.

## ما يفعله
- مسار مرتب A1 → A2 → B1 → B2.
- وحدات ودروس فيديو مرتبة.
- Deutsch mit Ahmad Yaghi للقواعد/المفردات والمحادثة حيث يناسب.
- Easy German للنطق والقواعد التطبيقية والاستماع الطبيعي.
- موارد منفصلة للاستماع، القراءة، الكتابة والاختبارات.
- خطة يومية تُبنى حسب الوقت والتقدم.
- مراجعة متباعدة 1/3/7 أيام.
- Streak وتقدم حسب المهارة.
- اختبارات A1/A2/B1/B2 + تحديد مستوى إرشادي.
- حفظ كامل محلياً عبر localStorage.
- Dark/Light mode.
- Responsive.
